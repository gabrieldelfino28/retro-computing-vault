Sobre o Projeto

O Museu do hardware é uma aplicação Fullstack desenvolvida em Java com Spring Boot com o objetivo de catalogar e gerenciar hardware histórico — desde computadores clássicos até consoles e dispositivos móveis legados.

O projeto tem foco em boas práticas de Programação Orientada a Objetos (POO) e em uma arquitetura limpa e extensível, servindo também como estudo aprofundado de padrões de projeto e persistência com JPA/Hibernate.
